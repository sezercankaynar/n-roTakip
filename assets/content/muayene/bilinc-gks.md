> Puanlamak için: **Ölçekler → Glasgow Koma Skalası** (hesaplayıcı).

## Bilinç düzeyleri
- **Uyanık (alert):** gözleri açık, çevresiyle ilgili, uygun yanıt veriyor
- **Letarji:** uykuya eğilimli, sesle kolayca uyanıyor, uyanık kalmakta zorlanıyor
- **Stupor:** ancak güçlü veya ağrılı uyaranla kısa süre uyanıyor
- **Koma:** hiçbir uyaranla uyanmıyor, gözler kapalı

Bu terimler kişiden kişiye farklı anlaşılabildiği için **GKS ile birlikte, yanıtın kendisini tanımlayarak** yazmak daha güvenlidir.

## Glasgow Koma Skalası (GKS)

| Bölüm | Yanıt | Puan |
|---|---|---|
| **Göz açma (E)** | Kendiliğinden | 4 |
| | Sesle | 3 |
| | Basıyla (ağrılı uyaranla) | 2 |
| | Yok | 1 |
| **Sözel yanıt (V)** | Yönelimi tam | 5 |
| | Konfüze | 4 |
| | Uygunsuz kelimeler | 3 |
| | Anlamsız sesler | 2 |
| | Yok | 1 |
| **Motor yanıt (M)** | Emirlere uyuyor | 6 |
| | Ağrıyı lokalize ediyor | 5 |
| | Normal fleksiyon (çekme) | 4 |
| | Anormal fleksiyon (dekortike) | 3 |
| | Ekstansiyon (deserebre) | 2 |
| | Yok | 1 |

Toplam **3–15**. Bileşenler ayrı ayrı yazılır: örneğin **"GKS 10 (E3 V3 M4)"**.

## Nasıl değerlendirilir?
1. **Gözlem:** uyaran vermeden hastaya bak
2. **Sesle uyar:** normal sesle, gerekirse yüksek sesle adını söyle
3. **Fiziksel uyaran:** önce merkezi (trapez sıkıştırma, supraorbital bası) veya periferik (tırnak yatağına bası); **sternuma sert ovma önerilmez** (doku hasarı)
4. Motor yanıtta **en iyi yanıt** puanlanır (iki taraf farklıysa iyi olan taraf; fark ayrıca kayda yazılır)

## Değerlendirilemeyen durumlar (NT)
- **Entübe/trakeostomili hasta:** sözel yanıt değerlendirilemez, "**VT**" yazılır (ör. E3 VT M5); toplam puan verilmez
- Göz kapaklarında ödem: göz açma değerlendirilemez
- Afazi, işitme kaybı, dil engeli, sedasyon ve kas gevşetici kayda yazılır

## Önemli noktalar
- **GKS ≤ 8:** genellikle ağır beyin hasarı; havayolu koruması değerlendirilir
- **2 puan veya daha fazla düşüş** (motor yanıtta 1 puan bile) hemen bildirilir
- Entübe hastada beyin sapı reflekslerini ve solunumu da içeren **FOUR skoru** kullanılabilir
